# MAD Project — Real-Time Object Detection App

A mobile object detection app built with **Expo / React Native** on the frontend and a **Flask + YOLOv11** backend that also estimates each detected object's real-world X/Y/Z position using camera calibration.

## Structure

```
MAD_Project/
├── backend/                  # Flask API + YOLO detection + camera calibration
│   ├── app.py                 # Main Flask server (/detect endpoint)
│   ├── calibrate.py            # Generates camera_calibration.npz from checkerboard photos
│   ├── find_xyz.py              # Standalone script: detect + estimate XYZ on a single test image
│   ├── test_calibration.py      # Validates calibration accuracy (reprojection error)
│   ├── calibration/              # Checkerboard photos used for calibration
│   ├── camera_calibration.npz     # Saved camera intrinsics (generated by calibrate.py)
│   └── test.jpeg                   # Sample test image
│
└── expo/object-detection-app/    # React Native (Expo Router) mobile app
    └── app/
        ├── _layout.tsx             # Navigation stack
        ├── index.tsx                 # Home screen
        ├── welcome.tsx                 # Splash screen
        ├── login.tsx                     # Login / Register (in-memory demo auth)
        └── detection.tsx                   # Camera/gallery capture + detection results
```

## Backend Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install flask ultralytics opencv-python numpy pillow

# Download YOLO weights (not included in this repo — see below)
python app.py
```

### ⚠️ Model weights not included
`yolo11x.pt` (~110MB) and `yolo11n.pt` are excluded from version control (too large for GitHub / not meant for git).
Download them from the [Ultralytics releases page](https://github.com/ultralytics/assets/releases) and place them in `backend/`, or run:

```python
from ultralytics import YOLO
YOLO("yolo11x.pt")   # auto-downloads on first use
```

## Frontend Setup

```bash
cd expo/object-detection-app
npm install
npx expo start
```

Before running, update the backend URL in `app/detection.tsx`:

```ts
const FLASK_API_URL = "http://<YOUR_LOCAL_IP>:5000/detect";
```

Your phone (running Expo Go) and your computer (running Flask) must be on the same Wi-Fi network.

## Notes

- Login/Register currently uses an in-memory array as a placeholder database — accounts do not persist between app restarts. Replace with a real backend/auth provider for production use.
- Depth (Z) estimation assumes a fixed real-world object width (`REAL_WIDTH = 0.05m`) — accurate only for objects close to that size.
